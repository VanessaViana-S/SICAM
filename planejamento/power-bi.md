# Planejamento de indicadores

A utilização do Power BI está prevista para uma etapa posterior do projeto.

A base estruturada no Microsoft Lists poderá futuramente servir como fonte para indicadores e painéis relacionados ao acompanhamento dos conflitos.

Possíveis indicadores incluem:

- quantidade de conflitos cadastrados;
- distribuição territorial;
- situação dos acompanhamentos;
- natureza dos conflitos;
- evolução dos registros;
- movimentações;
- indicadores relacionados às demandas acompanhadas.

O Power BI ainda não foi implementado neste projeto.
