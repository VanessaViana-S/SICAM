# Evolução para Power Apps

## Situação atual

O SICAM ainda não possui uma aplicação implementada no Power Apps.

A solução atualmente utilizada está implementada no Microsoft Lists.

## Próxima etapa

A próxima etapa do projeto consiste na reconstrução do SICAM utilizando Power Apps.

A nova estrutura criada no Microsoft Lists será utilizada como fonte de dados para a futura aplicação.

## Protótipos

Foram desenvolvidos protótipos conceituais das principais telas:

- Tela inicial
- Consulta de conflitos
- Cadastro de novo conflito
- Detalhes do conflito

## Objetivo

A futura aplicação deverá proporcionar uma experiência de utilização mais estruturada, permitindo centralizar as funcionalidades de cadastro, consulta e acompanhamento.

## Observação

Os protótipos apresentados no projeto representam a interface planejada e não uma aplicação Power Apps já implementada.
