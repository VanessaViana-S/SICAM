# Projeto SICAM

## Contexto

O SICAM — Sistema Integrado de Conflitos Agrários e Mediação — surgiu a partir da necessidade de melhorar a organização, o registro e o acompanhamento das informações relacionadas aos conflitos agrários.

## Problema identificado

O acompanhamento anteriormente realizado por meio de Microsoft Forms e Excel Online apresentava limitações relacionadas à organização, padronização e evolução da estrutura de dados.

## Proposta

Foi realizada uma reestruturação da base de informações utilizando o Microsoft Lists, aproveitando a infraestrutura disponível no Microsoft 365.

A proposta busca melhorar a organização dos registros e preparar a estrutura para futuras integrações e automações.

## Situação atual

A solução encontra-se implementada no Microsoft Lists e está sendo utilizada gradualmente pela equipe.

A migração dos dados existentes está ocorrendo de forma gradual.

## Evolução planejada

A próxima etapa consiste na reconstrução do SICAM utilizando Power Apps, tendo a estrutura criada no Microsoft Lists como fonte de dados.

Também estão previstas futuras possibilidades de integração com Power Automate e Power BI.

Este documento não contém dados reais ou informações institucionais sensíveis.
